# Rosters

**Rosters** lists children enrolled in a ministry so leaders can plan rooms, follow up on interest-only families, and confirm who should appear at check-in.

![Roster](/help/screenshots/leader-roster.png)

## Typical uses

- Count enrolled children before Sunday
- Confirm a child is in the right ministry after registration
- Coordinate with [check-in](/help/user-guide/check-in-out/check-in-process)

If someone is missing, check that they registered for the **current cycle** and chose **enrolled** (not only interest) for that ministry.
