# Program setup

Open **Ministries** (administrators) to add or edit a program.

![Ministry configuration](/help/screenshots/ministry-enrollment-config.png)

## Typical settings

- **Name and description** — what families read during registration
- **Active** — inactive ministries stay out of new registration options
- **Age or grade range** — gatherKids hides the ministry when a child is outside the range
- **Custom questions** — extra fields collected only for that ministry

## Registration cycles

Enrollment is tied to a **registration cycle** (for example, Fall 2026). Families register into the active cycle. Previous cycle enrollments remain on the household accordion for history.

## Groups

Some programs belong to a ministry group (for example, choirs) that shares communication settings. Edit groups from the Ministries screen when you need a shared contact or digest.
