# Check children out

1. On **Check-In**, find a child who is already checked in.
2. Select **Check Out**.
3. Complete the pickup verification fields (pickup name and PIN when your ministry uses them).
4. Confirm. The card returns to a checked-out state.

![Check-out](/help/screenshots/check-out.png)

## Tips

- Do not skip verification because the line is long.
- If pickup does not match the household, pause and find a leader.
- Late pickup still uses the same check-out action so attendance times stay accurate.

See also [Check-in overview](/help/user-guide/check-in-out/overview).
