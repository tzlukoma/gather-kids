# Check children out

1. On **Check-In**, find a child who is already checked in.
2. Select **Check Out**.
3. Complete the pickup verification fields (pickup name and PIN when your ministry uses them).
4. Confirm. The card returns to a checked-out state.

![Check-out](/help/screenshots/check-out.png)

## Tips

- Do not skip verification because the line is long.
- If pickup does not match the household, pause and find a leader.
- Late pickup still uses the same check-out action so attendance times stay accurate.

## Moving a child to another event

When a child who is already checked in needs to go to a different event (for example, from Sunday School to another event your church runs), use **Transfer** instead of checking them out.

1. On **Check-In**, with the event they are in now selected, find the child. You can also start from **Rosters**, where Transfer appears next to **Check Out** for any child who is checked in.
2. Select **Transfer**.
3. Choose the event they are moving to and confirm.

The child stays checked in and on site, and their arrival time is kept. A transfer is not a pickup, so no pickup details are recorded. When the family collects the child, check them out from the new event as usual, with the same verification.

Only events set up for check-in can be chosen. Transfer is available to admins and ministry leaders.

See also [Check-in overview](/help/user-guide/check-in-out/overview).
