# Check-in and check-out overview

Check-in records who is present. Check-out records who picked the child up. Both live under **Check-In** in the leader menu.

![Check-in list](/help/screenshots/check-in-list.png)

## Why it matters

- Leaders know who is in the room
- Allergies and notes are visible on the child card
- Pickup is limited to the process your ministry uses (name / PIN)

## Event

Select the gathering (for example, Sunday service) before checking children in so attendance is stored against the right event.

## Managing events (admins)

Admins manage the list of events under **Events** in the menu.

- **Add** an event to make it available for check-in and as a transfer destination straight away.
- **Rename** an event to change its name everywhere, including on past attendance. The event and its history stay the same.
- **Archive** an event you no longer run. It disappears from the event pickers and takes no new check-ins, but its history is kept. Any child still checked in to it can be checked out or transferred out as usual. Its door stays available until the last child has left. You can **Restore** an archived event at any time.
- **Delete** is only available for an event that has never had attendance. An event with any history can be archived instead, so attendance records are never lost.

Changing events never enrolls or unenrolls a child in a ministry.
