# Bible Bee overview

Bible Bee in gatherKids tracks which children are enrolled in a competition year, which scriptures they are assigned, and how progress is going.

![Bible Bee overview](/help/screenshots/bible-bee-overview.png)

Administrators open **Bible Bee** to manage the year. Guardians with an enrolled child can see progress from the household area when that feature is enabled for the cycle.

See [Competitions](/help/user-guide/bible-bee/competitions) and [Progress tracking](/help/user-guide/bible-bee/progress-tracking).
